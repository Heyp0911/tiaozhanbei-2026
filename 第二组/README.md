## 一、背景

### 1.1 核心概念

在"双碳"战略和新型电力系统建设背景下，我国县域普遍面临一个矛盾：**分布式光伏等绿电资源丰富，但波动性强、就地消纳能力不足**。与此同时，AI 应用正从大型云端向边缘侧下沉。

本作品提出 **"算随电走"** 新范式——在县域布局边缘算力节点，让可弹性调度的 AI 计算任务主动跟随绿电出力的节奏：光伏高峰时集中执行弹性任务，光伏归零时只跑刚性任务。相比传统"电随算走"，"算随电走"将算力从刚性负荷转变为柔性可调节负荷。

### 1.2 本组定位

| 组别 | 负责章节 | 核心产出 |
|------|----------|----------|
| 第一组 | 第二章：未来产业潜在方向研判 | 产业定义、SWOT分析、县域适配性、方向对比 |
| **第二组（本组）** | **第三、四章** | **关键技术体系、MILP模型、三场景仿真、闽清验证、AI Demo、IRR分析** |
| 第三组 | 第五、六章：培育路径与商业模式 | 三阶段路径、试点方案、商业模式、风险应对 |

## 三、模块一：分布式绿电出力预测（技术一）

### 3.1 功能概述

将 NASA POWER 卫星气象数据转化为光伏出力曲线，同时为闽清县验证构造绿电数据。

**核心文件**：`green_power_predictor.py`（~470 行）

### 3.2 核心算法

**物理模型（光伏出力计算）**：

```
T_cell(t) = T2M(t) + (NOCT - 20) / 800 × GHI(t)
P_pv(t)   = P_rated × (GHI(t) / G_STC) × [1 + k_temp × (T_cell(t) - T_STC)]
P_pv_ac   = P_pv × system_efficiency  (DC → AC 并网)
```

**K-Means 聚类**：365天×24h → 4条典型日曲线（晴天高峰/多云中等/阴天低日照/雨天低谷）

**波动性量化**：标准差、最大爬坡率(MW/h)、有效发电小时数、峰谷差比、95%置信区间

**闽清小水电**：基于径流式小水电典型特征构造丰水期(基荷70%)和枯水期(基荷30%)曲线

### 3.3 输出

| 输出文件 | 内容 |
|------|------|
| `data/green_power_curves.csv` | 4 条 K-Means 典型日光伏出力曲线 |
| `outputs/通用模型/green_power_curves.png` | 四条曲线叠加对比图 |
| `outputs/通用模型/fluctuation_analysis.png` | 波动性箱线图 + 95% 置信带 |
| `data/minqing_raw_days.csv` | 闽清 3 个真实日期（晴天/阴天/波动日）逐时 GHI |
| `data/minqing_hydro_curve.csv` | 闽清小水电丰/枯水期典型日曲线 |

## 四、模块二：源网荷储算碳协同优化（技术二+三+四）

### 4.1 功能概述

作品核心仿真引擎。将分布式光伏、外部电网、储能系统、边缘算力任务和碳排放统一建模为 **MILP** 问题，求解最小化系统总运行成本的调度方案。

**核心文件**：`milp_optimizer.py`（~740 行）

### 4.2 关键参数一览

| 类别 | 参数 | 取值 | 依据 |
|------|------|:---:|------|
| 光伏 | 额定装机 / 系统效率 | **25 MW** / 94.52% | 高渗透率县域场景 |
| 电网 | 接入容量 / 碳因子 / 碳价 | 20 MW / 0.581 tCO₂/MWh / 80 元/t | 生态环境部 + 全国碳市场 |
| 储能 | 默认容量 / 充放电倍率 / 效率 | **50 MWh** / 0.5C / 93% | 25MW光伏×2h配比 |
| 算力节点 | IT额定功耗 / 空闲 / PUE | 5 MW / 1.0 MW / 1.4 | 边缘数据中心典型值 |
| AI 任务 | 刚性:弹性:温冷 | **19.2 : 36.0 : 12.0 MWh/天** | 节点利用率76%，留有调度裕量 |
| 电价 | 峰/平/谷 + 需量费 | 0.80 / 0.58 / 0.35 元/kWh | 福建省发改委2025年8月代理购电 |

> **V2 参数设计要点**：任务总量从 96→67.2 MWh/天，留出 30% 调度裕量。在 S2（电随算走）中算力恒定 3.8 MW IT，S3（算随电走）中算力在 1.8~5.0 MW IT 间动态变化——功率差异肉眼可见。

### 4.3 模型定义

#### 建模对象（"源网荷储算碳"六元）

| 对象 | 决策变量 | 含义 |
|------|------|------|
| **源** | P_pv_use[t], P_pv_curt[t] | 光伏利用/弃光功率 |
| **网** | P_grid[t] | 电网购电功率 |
| **荷** | P_load_base[t] | 县域基础用电负荷 |
| **储** | P_ch[t], P_dis[t], SOC[t], u_ch[t], u_dis[t] | 充放电功率、荷电状态、互斥标志 |
| **算** | P_rigid[t], P_elastic[t], P_cold[t] | 刚性/弹性/温冷任务功率 |

#### 约束条件（10 类）

| 编号 | 约束 | 说明 |
|:---:|------|------|
| ① | 功率平衡 | P_pv_use + P_grid + P_dis = P_load + P_ch + P_compute×PUE |
| ② | 光伏出力 | P_pv_use + P_pv_curt = P_pv_avail |
| ③ | 储能充放电互斥 | u_ch[t] + u_dis[t] ≤ 1（二进制 MILP） |
| ③-bis | 弃光时禁止放电 | Big-M: P_pv_curt ≤ M×(1-u_dis) |
| ④ | SOC 连续性 + 上下限 | 日循环约束 SOC[23] ≥ SOC[0] |
| ⑤ | 算力节点总容量 | P_rigid+P_elastic+P_cold+P_idle ≤ P_node_rated |
| ⑥⑦⑧ | 任务约束 | 弹性/温冷日总量必达 + 刚性不可调节 |
| ⑨ | 电网购电上限 | 动态调整确保可行域非空 |
| ⑩ | 两部制需量约束 | P_peak ≥ P_grid[t]（所有时段） |

#### 目标函数

```
min Z = C_grid + C_carbon + C_curtail + C_battery_depreciation + C_demand

C_grid    = Σ P_grid[t] × price[t] × 1000     （购电成本）
C_carbon  = Σ P_grid[t] × 0.581 × 80           （碳排放成本）
C_curtail = Σ P_pv_curt[t] × 0.55 × 1000      （弃光惩罚=平段电价）
C_battery = 直线折旧法日折旧额                  （储能固定成本）
C_demand  = P_peak × 1000 × 需量费单价          （两部制需量费）
```

#### 三场景定义

| 对比维度 | 场景一：无算力 | 场景二：固定算力（电随算走） | 场景三：弹性算力（算随电走） |
|----------|:---:|:---:|:---:|
| 刚性任务 | 无 | 24h 均匀固定 (0.8 MW) | 24h 均匀固定（不可调） |
| 弹性任务 | 无 | 24h 均匀固定 (1.5 MW) | **MILP 自动优化分配** |
| 温冷任务 | 无 | 24h 均匀固定 (0.5 MW) | **MILP 自动优化分配** |
| IT 负荷范围 | 0 MW | 恒定 3.8 MW | **1.8~5.0 MW 动态变化** |
| 求解类型 | LP | LP | MILP（48个二进制变量） |

### 4.4 输出指标

每个场景输出 10+ 个核心指标：绿电消纳率、弃电率、系统总成本、碳排放量、单位算力碳排放、任务完成率、算力节点利用率、峰值需量、弹性任务调节量（仅S3）。

## 八、模块五：IRR 投资回报对比

**核心文件**：`irr_calc.py`（~370 行）

### 方法

1. K-Means(k=3) 对全年 365 天光伏聚类 → 3 条典型日曲线（PV_high 165天/PV_mid 123天/PV_low 77天）
2. 对每条曲线跑三场景 MILP → 按天数加权年度化
3. 构建 20 年现金流模型（含设备更换、折旧、税收、残值）
4. Newton 法计算 IRR

### 投资参数

| 项目 | 单价 | 容量 | 投资额 |
|------|:---:|:---:|:---:|
| 光伏系统 | 3,000 元/kW | 25 MW | 7,500 万元 |
| 储能系统 | 1,000 元/kWh | 50 MWh | 5,000 万元 |
| 算力节点 | 15,000 元/kW_IT | 5 MW | 7,500 万元 |

### 对比结果

| | S1 无算力 | S2 电随算走 | **S3 算随电走** |
|------|:---:|:---:|:---:|
| 总投资 | 12,500 万 | 20,000 万 | 20,000 万 |
| 年电网成本 | 1,102 万 | 1,252 万 | **995 万** |
| 年净利润 | -413 万 | 1,483 万 | **1,676 万** |
| **IRR** | 负值 | **5.43%** | **7.19%** |
| **回收期** | >20年 | 9.7 年 | **9.0 年** |

> 🔥 **核心结论**：相同硬件投入 2 亿元，S3 的 IRR 比 S2 高 **1.76 个百分点**。仅靠弹性调度，每年多赚 193 万元，回收期缩短 8 个月。
